# Concept Art Brief

Status: **approved brief for visual exploration**

These concepts validate hierarchy/mood. They do not replace responsive specs or freeze pixel values.

## Board A — Core product

### 1. Laboratory — desktop

Show a real playable screen:

- midnight-blue modern observatory/lab shell;
- warm amber desk/reaction stage;
- persistent left navigation;
- two large element slots in center;
- explicit `Combina` button;
- visible reaction/result area;
- right searchable element library;
- illustrated element cards;
- Discovery Level, not currencies;
- cozy modern-magical, not medieval.

Example selected inputs:
Acqua + Terra.

### 2. Laboratory — mobile

Portrait phone.

Show:

- compact level/discovery header;
- large touch-friendly slots;
- Combine;
- result area;
- favorites/search;
- three-column element library;
- bottom navigation;
- same identity as desktop, not a separate app.

### 3. Collection / Set detail

Switch central surface toward illustrated field guide:

- warm ivory paper surface inside dark shell;
- Set header;
- visible completion without global hidden denominator;
- illustrated grid;
- some known elements;
- one legitimate visible unknown if appropriate;
- no placeholders for secret Sets.

Preferred Set:
Mondo or Piante.

### 4. Element detail

Hero element art with editorial field-guide treatment.

Show:

- element name;
- Set;
- short description;
- first discovered recipe;
- alternate recipe block;
- “ha ancora possibilità” state;
- small local relationship graph.

Preferred element:
Acqua.

## Board B — Mystery and expansion

### 5. Anomaly Archive

Same app shell, darker indigo glass center.

Show known pair:
Luna + Vita.

State:
Reazione instabile.

Do not reveal future result.

Visual motif:
incomplete orbit/sigil, restrained violet refraction.

### 6. Discovery Map

Dark cosmic canvas.

Focus on one local neighborhood only.

Nodes should be illustrated cards/tokens connected by restrained glowing edges.

Include known branches around:
Stella / Pianeta / Luna / Mondo.

No giant unreadable graph.

### 7. Arcano reveal

Same Laboratory, transformed rather than replaced.

Moment:
Mito + Energia → Magia.

Then visual cue that an old anomaly can be revisited.

Add:

- violet-gold stabilized impossible geometry;
- subtle iridescence;
- hidden Set `Magia` appearing;
- no medieval parchment overload;
- the room still clearly matches the normal Lab.

## Art style

- polished 2D product concept art;
- premium cozy indie game;
- painterly illustrated cards;
- modern UI;
- soft material texture;
- glass + dark wood + restrained brass;
- high legibility;
- realistic product UI density, not marketing splash.

## Avoid

- glossy generic mobile game;
- excessive neon;
- medieval alchemy room;
- childish cartoon;
- unreadable fantasy fonts;
- dozens of currencies;
- combat stats;
- fake 3D game board;
- photorealistic UI mockup with illegible text.

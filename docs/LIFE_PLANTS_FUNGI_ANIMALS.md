# Life, Plants, Fungi & Animals — Content Expansion v0

Status: **content design draft**

Purpose: expand the first 43-element skeleton into a richer biological branch and test whether `Vita`, `Piante`, `Funghi` and `Animali` can support meaningful discovery rather than simple taxonomy.

This is not yet a final canonical recipe list.

## Design principle

The game should not attempt to recreate the entire tree of life.

We want recognizable, combinable archetypes that create useful future ingredients.

Species are selected because they:

- are immediately recognizable;
- suggest intuitive combinations;
- support later folklore/fantasy;
- support Collections;
- create varied visual assets.

## Animali set — design strategy

Animali should be one large Set, not separate Sets for mammals, birds, insects, etc.

Those families become:

- Tags;
- Collections;
- hint categories.

This avoids turning the catalog into taxonomy homework.

## Animal entry point

Preferred biological bridge:

- Vita + Energia → Movimento
- Vita + Movimento → Creatura

`Creatura` belongs to Vita, not Animali.

The first concrete animal discovered from Creatura reveals Animali.

Possible first animal:

`Creatura + Oceano → Pesce`

This makes the transition readable:

life → movement → creature → animal.

## Animal recipe design rule

Do not force every species directly from `Creatura + Habitat`.

Preferred recipe ladder:

1. establish a broad recognizable branch;
2. use another discovered trait/concept to specialize.

Example direction:

- Creatura + Vento → Uccello
- Uccello + Notte → Gufo
- Uccello + Oceano → Gabbiano
- Uccello + Acqua → Anatra

Likewise:

- Creatura + Terra → Mammifero or small mammal archetype
- branch further using Forest, Mountain, Night, etc.

### Open question: category elements

We need to decide whether elements such as:

- Uccello
- Mammifero
- Rettile
- Insetto

are valid collectible elements or merely invisible tags.

Using them as elements makes species recipes more legible but mixes taxonomic categories and concrete species.

Using them only as tags creates a harder recipe-authoring problem.

Current preference:

**Allow a small number of category/archetype elements when they are useful gameplay ingredients.**

They should have distinct artwork and feel like meaningful concepts, not spreadsheet labels.

## Future fantasy value

Animal choices should deliberately support later transformations.

Examples for future design:

- Lupo + Luna → werewolf-like anomaly/creature
- Cavallo + Magia → unicorno
- Uccello + Fuoco → fenice
- Serpente + Ali/Aria → dragon-like branch
- Gatto + Vuoto → astral creature
- Polpo + Abisso → cosmic creature
- Cervo + Spirito → forest spirit

These examples are not canonical yet.

The point is to select normal animals that remain valuable deep into the game.

## Content quality filter

Every proposed biological element should pass at least two of:

- has an intuitive discovery route;
- supports another recipe later;
- belongs to an appealing Collection;
- is visually distinctive;
- supports a fantasy/abstract future transformation;
- teaches a useful concept.

Do not add species merely to inflate the Set count.

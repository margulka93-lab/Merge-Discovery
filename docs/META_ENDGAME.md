# Meta, Retention, Achievements & Endgame

Status: **product design v1**

The game should invite return through unfinished curiosity, not punishment.

## Explicit non-goals

No core design based on:

- daily login streak;
- expiring energy;
- “come back in 4 hours” timers;
- punishment for missing a day;
- mandatory daily quest treadmill.

## Return experience

On returning after time away, show a compact contextual summary only if useful.

Possible items:

- last discovery;
- newly available possibilities after content/update/unlock;
- anomaly that became revisitable;
- Collection close to completion.

Example:

> Bentornata. Ultima scoperta: Pianeta.  
> 2 elementi hanno nuove possibilità.

No fake “we missed you” pressure.

## Optional research prompts

Instead of daily quests, the game may surface non-expiring prompts.

Examples:

- “Scopri qualcosa che nasce dall’Acqua.”
- “Completa un’altra parte del Ciclo dell’acqua.”
- “C’è ancora qualcosa da capire sulla Luna.”

Prompts:

- never expire;
- can be rerolled/hidden;
- do not gate content;
- are generated from valid current state without revealing secrets.

## Achievements

Achievements celebrate milestones/actions.

Candidate categories:

### Discovery

- Prima scintilla — first new element
- Due volte lo stesso — first A+A discovery
- Un’altra strada — first alternate recipe

### Exploration

- Archivista — first anomaly
- Ritorno al mistero — resolve an old anomaly
- Dietro il velo — discover a hidden Set

### Collection

- first Set completion
- several Collection chapters

### Depth

- discover a rare/secret element
- reconnect an Origini element in a late Era

Avoid achievements for:

- consecutive days;
- excessively long sessions;
- never using hints;
- refusing accessibility features.

Hints must not invalidate achievements.

## Profile statistics

Useful:

- discoveries;
- normal Sets completed;
- hidden Sets found;
- alternate recipes found;
- anomalies resolved;
- favorite element.

Avoid vanity metrics that encourage spam:

- total combines as a primary score;
- hours played leaderboard.

## Endgame philosophy

There is no hard “game over”.

The main authored progression can have an **Era culmination**.

Preferred emotional endpoint:

the player reaches Impossibile and demonstrates that even the universe’s rules can become ingredients.

After a major culmination reveal:

> Hai spinto la scoperta oltre le regole che l’avevano iniziata.

Then the Catalog remains playable.

## Completion layers

### Main progression complete

All required Era keystones reached.

### Set completion

Known normal Sets completed.

### Collector completion

Visible optional/bonus content completed.

### Secret discovery

Never required for the game to acknowledge main completion.

There is deliberately no permanent global 100% denominator that leaks future expansions.

## Expansion compatibility

New content can add:

- recipes for old elements;
- bonus elements to completed Sets;
- new Collections;
- new hidden Sets;
- new Eras.

Previously earned completion badges remain historically valid.

A completed Set can show:

> Completo · Nuove scoperte disponibili

rather than revoke the badge.

## Post-launch content philosophy

Prefer meaningful themed expansions over constant tiny churn.

Examples:

- deeper oceans;
- seasonal folklore;
- astronomy expansion;
- dream/spirits expansion.

New content should reconnect old ingredients.

## Notifications

Not required for MVP.

If Android notifications are added later:

- off by default or explicit opt-in;
- only for meaningful requested events;
- never “your energy is full”.

## Monetization stance

No monetization is required to validate the game.

Architecture must not assume ads, gems or IAP.

If monetization is explored later, preferred directions are:

- paid full game;
- one-time expansion packs;
- cosmetic/supporter content that does not sell discovery answers.

Avoid pay-to-discover, paid stamina and hint coercion.

## Analytics stance

Analytics is deferred.

If added, collect product interaction metrics, not content of personal data.

The game must function with analytics disabled.

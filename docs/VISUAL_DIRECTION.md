# Visual Direction

Status: **art direction draft v1**

## Core identity

**Modern magical observatory + illustrated field guide + warm discovery laboratory.**

The game should feel:

- cozy;
- intelligent;
- magical without looking medieval;
- premium but not sterile;
- readable on small screens;
- visually expandable from science to fantasy.

## Avoid

- generic glossy mobile-game UI;
- neon cyberpunk;
- medieval parchment everywhere;
- oversaturated cartoon candy;
- flat enterprise dashboard aesthetics;
- hyper-detailed photorealism.

## Base atmosphere

Primary environment:

a modern, cozy observation laboratory where scientific instruments, illustrated cards and subtle impossible phenomena coexist.

Visual materials:

- dark midnight blues;
- warm amber light;
- muted brass/gold;
- glass;
- dark wood;
- soft paper/ivory surfaces;
- restrained violet for anomalies.

## UI surfaces

### Laboratory

Dark atmospheric background with warm local light.

Combination cards remain highly legible.

### Catalog

Brighter field-guide / illustrated-atlas surface.

Purpose:

make long reading and collection browsing comfortable.

### Anomalies

Darker glass-like surface with unstable violet/indigo distortion.

### Arcano

Do not swap the entire UI theme.

Instead introduce:

- iridescent highlights;
- violet-gold sigils;
- subtle impossible geometry;
- different particle behavior.

The same laboratory has learned a new language.

## Element art

Preferred style:

- painterly 2D illustration;
- simplified silhouette;
- soft texture;
- icon readability at small sizes;
- enough detail to make full-card art satisfying.

Each element should work in three representations:

1. tiny icon;
2. catalog card;
3. large reveal/detail art.

This must inform the asset pipeline later.

## Card anatomy

Element card:

- art occupies most of card;
- name below/overlay with high contrast;
- small Set indicator;
- minimal rarity treatment;
- no cluttered stat blocks.

There are no combat stats.

## Set identity

Each Set can have:

- accent hue;
- icon motif;
- subtle particle/texture motif.

But all Sets share one design system.

Examples:

- Origini — ivory/gold starburst;
- Cosmo — indigo/cobalt;
- Mondo — mineral/teal;
- Vita — fresh green;
- Piante — moss/leaf;
- Funghi — earthy plum;
- Animali — warm ochre;
- Umanità — terracotta;
- Cultura — parchment/ink;
- Tecnologia — steel/cyan;
- Magia — violet/gold;
- Spiriti — pale blue/opal;
- Sogni — lavender;
- Paradossi — impossible gradients/geometry.

Exact color values deferred.

## Motion language

### Normal combine

Elements drift toward center, overlap, resolve.

### New element

Soft burst + focus pull.

### Set reveal

Background reacts; new icon/label emerges from the discovery.

### Anomaly

Inputs distort but fail to resolve.

### Resolved anomaly

Use the same anomaly visual vocabulary, now stabilizing.

This makes payoff visually legible.

## Sound direction

High-level only for now:

- tactile soft clicks for selection;
- warm low impact for combine;
- crystalline short motif for discovery;
- deeper harmonic motif for Set reveal;
- unstable granular shimmer for anomaly;
- expanded version of anomaly sound when resolved.

Avoid:

- casino jingles;
- aggressive reward fanfares;
- constant bubbly mobile-game noises.

## Typography

Need two roles:

- highly readable modern UI sans;
- optional editorial/display face for Set names and major reveals.

Avoid ornate fantasy body text.

## Logo direction

Working title `Merge Discovery`.

Logo should suggest:

- combining;
- orbit / relationship;
- discovery;
- not traditional merge-number gameplay.

Possible mark:

two small orbiting elements forming a third spark.

## Responsive art rule

Do not rely on text baked into illustrations.

UI text remains real interface text.

Art crops safely in portrait and landscape.

## Concept directions to visualize

### A — Observatory Lab

Dark navy interface, warm laboratory center, illustrated element cards, brass accents.

Best for:
mystery and premium atmosphere.

### B — Modern Field Guide

Lighter ivory catalog, illustrated atlas feel, clean cards, dark lab workspace.

Best for:
collection readability and cozy tone.

### C — Living Cosmos

More atmospheric and magical, with the discovery graph visibly woven through the interface.

Best for:
wonder, but risks visual overload.

Current preferred direction:

**A as shell + B for collection surfaces + restrained C during major reveals.**

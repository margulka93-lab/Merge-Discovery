# Set & Progression Framework

Status: **stable macro-structure v3**

## Core rule

The player progresses from physical reality toward life, culture, abstraction and impossibility.

Structures:

- Era — macro progression;
- Set — primary catalog family;
- Collection — optional thematic grouping;
- Tag — semantic metadata.

## Unlock channels

A Set may reveal through:

1. progression eligibility;
2. discovery;
3. hybrid eligibility + discovery;
4. secret trigger.

Level alone should rarely be the dramatic reveal.

## Era I — Origini

Working level band:
**1–8**

Primary Sets:

- Origini
- Cosmo

Origini contains primitive matter/energy concepts including Plasma and Gas.

Purpose:

- teach pair combination;
- establish reusable foundational concepts;
- teach A+A;
- reveal first announced new Set.

Keystone:

`Plasma + Gravità → Stella`

Stella reveals **Cosmo**.

## Era II — Mondo

Working level band:
**9–16**

Primary Set:

- Mondo

Mondo contains geology, waters and atmosphere as one player-facing domain.

Collections/Tags may include:

- Geologia
- Acque
- Clima
- Fenomeni atmosferici
- Terre emerse

Purpose:

- turn cosmic construction into recognizable places/processes;
- teach alternate recipes;
- increase cross-Set reuse.

## Era III — Vita

Working level band:
**17–26**

Primary Sets:

- Vita
- Piante
- Funghi
- Animali

Visibility:

- Vita — discovery reveal;
- Piante — revealed/foreshadowed after Vita;
- Funghi — hidden;
- Animali — announced once biological progression supports it.

Collections include animal families/habitats rather than separate Sets.

## Era IV — Umanità

Working level band:
**27–36**

Primary Sets:

- Umanità
- Cultura
- Tecnologia

Purpose:

- intentional creation;
- social organization;
- symbolic representation;
- knowledge/science;
- selective machines/technology.

Professions, food, arts subtypes and transport families remain optional content/Collections unless strong gameplay reuse justifies element status.

## Era V — Arcano

Working level band:
**37–46**

Primary Sets:

- Magia
- Creature fantastiche

Magia is hidden before reveal.

Arcano should:

- pay off old anomalies;
- reactivate old ingredients;
- transform myth/legend into a real rule of the universe.

Preferred bridge:

`Mito + Energia → Magia`

once Arcano eligibility is satisfied.

## Era VI — Invisibile

Working level band:
**47–56**

Primary Sets:

- Spiriti
- Sogni
- Emozioni

Purpose:

- non-physical ingredients;
- memory/desire/fear/symbolic relationships;
- poetic but internally consistent discovery.

## Era VII — Impossibile

Working level band:
**57+**

Primary Sets:

- Tempo e Dimensioni
- Paradossi
- Entità

Purpose:

- conceptual endgame;
- rare multi-stage discoveries;
- deep hidden content;
- universe rules becoming combinable concepts.

## Player-facing roadmap

The complete roadmap is never shown.

At any moment the player sees only:

- known Sets;
- selected announced future Sets;
- no placeholders for hidden/secret Sets.

## Set completion

Normal completion can reward:

- XP;
- Intuizione/hints if that resource survives playtest;
- cosmetic catalog/lab accents;
- optional Collections;
- flavor moments.

Do not use Set completion to farm currencies.

Secret additions do not revoke earned completion.

## Set maturity

A mature Set should have:

- enough elements to feel like a domain;
- internal recipes;
- cross-Set recipes;
- future reuse;
- distinct catalog identity.

The implementation seed intentionally uses underfilled proof Sets such as Funghi because its goal is systems validation, not launch content volume.

## Rarity

- Comune
- Insolito
- Raro
- Straordinario
- Segreto

Rarity is discovery character, not power.

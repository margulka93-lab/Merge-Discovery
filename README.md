# Merge Discovery

Discovery-driven combination game designed web-first and mobile-first, with Android as a later packaging target.

## Project status

**Pre-production / design phase. No gameplay implementation yet.**

The project is intentionally being designed in detail before Work/Codex implementation begins.

## Core fantasy

Start from the origins of the universe and combine discoveries to progressively reveal matter, worlds, life, civilization, technology and increasingly strange hidden domains.

The core reward is not upgrading an object into a higher-level copy. It is discovering **what a combination means**.

Examples:

- Acqua + Terra → Fango
- Vita + Oceano → Plancton
- Rettile + Arcano → ???
- Gatto + Vuoto → anomalous reaction until the relevant hidden domain is available

## Design pillars

1. **Discovery** — curiosity is the primary gameplay engine.
2. **Collection** — discoveries form a personal encyclopedia.
3. **Progression** — new levels and discoveries unlock new domains and experiment types.
4. **Mystery** — future content is not fully exposed in advance.
5. **Expansion** — the system must scale from a small first release to hundreds or thousands of curated elements.

## Design gate

Implementation starts only after the core design is sufficiently specified: combination rules, domains/sets, progression, catalog, anomalies, hints, onboarding, UX, visual direction, content model, validation and MVP scope.

See the documents in `docs/`.
